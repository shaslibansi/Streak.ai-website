# Google Analytics Setup for Streak.ai

1. Set the real Google Analytics measurement ID in your environment variables:
   - NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX

2. Optional Firebase web app values:
   - NEXT_PUBLIC_FIREBASE_API_KEY
   - NEXT_PUBLIC_FIREBASE_APP_ID

3. After deployment, visit Google Analytics and confirm that page_view events are appearing.
