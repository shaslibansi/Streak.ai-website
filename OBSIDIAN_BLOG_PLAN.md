## Goal
Turn the content already in the Obsidian vault into a searchable, SEO-friendly blog section for the Streak.ai website.

## Source Material to Use
The vault already contains strong content for blog posts:
- Index.md → product positioning and core value proposition
- competitive-domination.md → keyword strategy, content clusters, and SEO angles
- ai_master (updated 2026-07-10).md → AI food scanner and technical credibility
- streak_ai_app_architecture (updated 2026-07-10).mmd → app architecture and features for deeper posts

Start with 5 high-value posts that fit both SEO and product storytelling:
1. Privacy-first fitness app: why local storage matters
2. Best all-in-one fitness app with workouts, meals, and habits
3. How Streak.ai AI food scanning works
4. Why one-time purchase fitness apps beat subscriptions

## Implementation Plan
### Phase 1 — Curate and Rewrite
- Pick the best notes from the vault
- Rewrite them into beginner-friendly blog articles
- Keep the tone clear, practical, and product-focused
- Add a strong intro, subheadings, and a clear conclusion

### Phase 2 — Create Blog Pages
- Add one dedicated page per article under app/blog/
- Use the existing blog page pattern already in the project
- Add metadata, canonical URL, Open Graph tags, and Twitter cards
- Include FAQ schema and Article schema for SEO

### Phase 3 — Connect the Blog to the Site
- Add links from the homepage and blog index
- Add related posts at the end of each article
- Link new posts from the main blog listing page
- Add category or topic sections if needed

### Phase 4 — Improve Search Visibility
- Use target keywords in title, H1, first paragraph, and subheadings
- Add internal links between related articles
- Publish a short author bio and last-updated date
- Make sure each page is mobile-friendly and fast

### Phase 5 — Publish and Expand
- Launch the first 3 posts first
- Track which topics get the most engagement
- Turn the remaining Obsidian notes into follow-up articles
- Build a content calendar from the vault themes
